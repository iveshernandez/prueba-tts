# Kokoro TTS para Vercel

Proyecto web para generar voz con Kokoro-82M directamente en el navegador, sin API de TTS.

## Deploy en Vercel
Sube esta carpeta a GitHub y conecta el repositorio con Vercel. Vercel ejecutará `npm install` y `npm run build`.

## Voces españolas
- ef_dora
- em_alex
- em_santa

Kokoro.js usa el modelo `onnx-community/Kokoro-82M-v1.0-ONNX` y permite backend WebGPU o WASM.
